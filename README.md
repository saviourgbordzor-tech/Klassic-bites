# Klassic Bites — Premium Cafe & Catering Web App

A high-conversion, mobile-first digital storefront built for **Klassic Bites (Ho, Ghana)**. 

This is a custom-built, interactive web application designed to streamline custom cake orders, event catering, and daily lunch/fresh juice sales. It replaces the traditional back-and-forth messaging with an automated, app-like ordering experience.

## ✨ Key Features

*   **Interactive Custom Order Builder:** A fully dynamic form where customers select their category (Cakes, Food Baskets, etc.), size, flavour, and special instructions. 
*   **Automated 48-Hour Validation:** Built-in JavaScript logic automatically calculates the date and disables any date that does not meet the bakery's strict 48-hour notice policy.
*   **WhatsApp Receipt Generator:** When the customer hits "Send Order," the app compiles all their selections into a beautifully formatted, itemized receipt and opens it directly in the business's WhatsApp.
*   **Filterable Menu Categories:** An instant tab-filtering system allowing users to seamlessly switch between Celebration Cakes, Pastries, Lunch Haven, and Fruity Splash items.
*   **Cinematic UI (Parallax & 3D):** Features a stunning 3D parallax background that reacts to scroll depth, glassmorphism cards, and tactile, 3D-pressing buttons.
*   **Live Open/Closed Signal:** Automatically reads the local time in Ho and updates the hero badge to show if the cafe is currently open (Mon-Sat, 8am-8:30pm) or closed.
*   **Dual Theme:** Seamless switching between a crisp, vibrant "Fresh Cafe" light mode and a deep, premium "Forest Green" dark mode.
*   **Zero Hosting Costs:** Deployed entirely on static hosting. No monthly server fees, no database to maintain.

## 🛠 Tech Stack

*   **HTML5** (Semantic structure, SEO meta tags)
*   **CSS3** (Custom properties, Flexbox/Grid, 3D transforms, Parallax animations)
*   **Vanilla JavaScript** (No frameworks or jQuery, ensuring lightning-fast load times even on 3G networks)
*   **WhatsApp API** (Deep linking for automated checkout)

## 🚀 How to Deploy

1. Clone this repository or download the `index.html` file.
2. Open the file in any web browser to view it locally.
3. To connect it to a different WhatsApp number, open the `<script>` tag at the bottom of the file and update the `WA_PHONE` variable.
